# 采办岛 v1 产品规格

| 属性 | 值 |
| --- | --- |
| 状态 | Implemented through P15；原生 Pi Agent、短期会话、长期记忆与本地会话召回完成 |
| 工作名称 | 采办岛（Caiban Island，工程标识 caiban-island） |
| 平台 | Windows 10 1809+ 与 Windows 11（x64 优先，Arm64 后续评估） |
| 用户范围 | 单机、单用户、本地优先 |
| 分发 | 免证书、免安装 Windows 独立运行版；GitHub Release 仅提供清晰命名的 x64 EXE，首次运行可能触发 SmartScreen 提示 |
| 文档语言 | 中文；代码与公共符号使用英文 |

## 1. 产品目标

采办岛是一个常驻屏幕顶部的"灵动岛"式采购任务管理工具：平时几乎隐形，鼠标移到屏幕顶部中央即展开，几秒内确认"现在最重要的任务是什么、何时到期、下一步做什么"。全部操作在岛内三级面板完成，没有独立主窗口。

v1 成功标准（对应用户原始需求与飞书同步需求）：

1. Windows 独立运行版免安装分发，Win10(1809+)/Win11 双击即用，无证书要求；
2. 隐藏态为屏幕顶部中央极窄提示条，凸出 ≤4px，不遮挡浏览器标签与窗口按钮；鼠标移上平滑展开；
3. 展开面板按紧急程度排序显示任务卡片（名称、deadline、紧急度、进度、下一节点）；触摸屏左右滑动翻页浏览（惯性+吸附）；点击卡片进入详情；
4. 任务详情包含：名称、deadline、完整时间轴、各节点完成情况、所有相关网页 URL、文件链接、备注；
5. 节点拆分默认由内置 Pi Agent + DeepSeek 完成，Qoder MCP 保留兼容；AI 只产出草稿或逐次操作提案，用户确认后才写入正式数据；
6. 节点四态：已完成=绿、进行中=蓝、待完成=黄、已取消=中性灰；质感遵循灵动岛设计语言（深黑微磨砂、全圆角、克制动效）；
7. 任务结束/取消 → 卡片消失，全量记录本地归档（SQLite + Markdown/JSON 快照），可在系统内调取查看；
8. 全程流畅（动画 60fps 目标）、美观（黑色微磨砂透出桌面色彩）；
9. 任务可一键沉淀为飞书多维表格记录（个人令牌直连，免管理员审批；企业禁用令牌时以 CSV/Markdown 导出兜底）。

## 2. 用户与使用场景

目标用户：Windows 10/11 个人用户，管理采购任务、时间节点、相关网页与文件链接、以及杂事。

主要场景：

1. 工作中把鼠标移到屏幕顶部，快速查看最紧急任务与下一节点；
2. 在采办岛 L3 Agent 工作区用自然语言规划任务；也可继续从 Qoder 发送草稿；
3. 未登录 Qoder / 断网时，完全手动创建与编辑任务；
4. 关联网页 URL 与本地文件路径，从任务详情直接打开；
5. deadline 前收到 Windows 通知；系统通知被禁用时由岛内轻弹提示；
6. 任务完成或取消后归档，之后在归档页搜索、查看或恢复。

## 3. 产品界面：三级灵动岛

### 3.1 总体原则

- 同一窗口连续形变：L1→L2→L3 是同一透明窗口的尺寸与内容过渡，不弹第二个窗口；
- 岛位于主显示器顶部中央，不出现于任务栏与 Alt+Tab；
- 悬停展开不激活窗口、不抢焦点；点击、触摸或键盘操作后才允许激活；
- L2 鼠标离开安全边界后自动返回 L1；L3 保持当前工作台，使用可见“返回速览”按钮或 Esc 返回 L2；
- 前台窗口为真正全屏时暂停岛显示（P6 实现）；普通最大化窗口不算全屏。

### 3.2 L1 隐藏条

- 尺寸 96×6 逻辑像素，向上偏移约 2px，仅露出约 4px；位于主显示器顶部中央；
- 提示条为深色纯色胶囊，不显示文字与计数；圆角朝向屏幕中心（下方），贴屏顶的一侧保持平直；L1 原生窗口关闭 Acrylic，透明主体移到屏幕外，只让提示条进入工作区；
- 触发热区为顶部中央约 120×10 的坐标范围，实现不得使用会吞掉下层点击的拦截式透明覆盖窗口（用屏幕坐标轮询检测）。

### 3.3 L2 小面板（查看 + 轻量编辑）

- 默认 760×280 逻辑像素；宽度最小 560、最大为主屏工作区 80%；高度最大工作区 45%；
- 顶部工具行高 52px，命中目标 ≥44×44：新建、展开与更多；排序和设置收纳在更多菜单中，设置入口直接打开 L3 设置；
- 卡片区横向排列任务卡片，滑动/滚轮带惯性与卡片吸附；宽度足够时露出下一张卡片边缘，提示可横向滑动；
- 卡片按“任务名称 → 下一节点 → 风险/截止 → 可交互节点轴”组织；不在每张卡片重复显示“下一采购动作”；普通紧急度保持中性，不作为彩色警报；
- 节点轴优先展示上一节点、当前节点和下一节点，空间允许时显示更多节点；点击节点使用显式菜单切换待完成、进行中、已完成或已取消；
- 卡片主体是可聚焦控件，方向键/Home/End 浏览，Enter/点击进入 L3 当前任务工作台；右上角更多菜单提供完成并归档、取消并归档和永久删除。

### 3.4 L3 大面板（详细编辑 + AI 审核 + 归档 + 设置）

- 尺寸最大为主屏工作区 85%，圆角 24px 磨砂面板；可拖动、位置记忆；
- 默认是“当前任务工作台”：左侧 240px 任务栏承载搜索、任务切换以及草稿/归档/设置入口；右侧只呈现当前任务；
- 当前任务分为概览、采购节点、资料、提醒、备注，一次只显示一个主分区；概览首先显示下一采购动作、风险/截止与采购节点轨迹；
- 采购节点在一个视图中完成查看、编辑、排序和显式状态选择，禁止点击循环状态；
- Agent、草稿、归档、设置使用同一工作区呈现；设置分为常用、AI 与 Qoder、飞书同步、数据与高级；
- 窄屏时任务栏折叠为顶部任务选择器；顶栏提供可见“返回速览”按钮，Esc 同样返回 L2；L3 不因鼠标离开自动收起，退出应用仅由托盘提供。

### 3.5 托盘

- 无主窗口，托盘图标承载入口：打开采办岛、暂停/恢复灵动岛、退出；
- 收起岛不退出进程；仅托盘"退出"结束进程。

## 4. 功能需求

### 4.1 首次启动与生命周期

- FR-001 首次启动说明本地存储位置、Qoder MCP 可选性、托盘行为与免证书分发说明。
- FR-002 首次启动询问是否随 Windows 登录启动；拒绝不影响其他功能，设置中可随时修改。
- FR-003 未配置任何 AI 通道时，新建与编辑任务仍完整可用（手动模式）。
- FR-004 收起面板只是隐藏，进程常驻；只有托盘"退出"结束进程。
- FR-005 启动、系统唤醒或任务变化后，核对数据库与已计划提醒的一致性。

### 4.2 岛窗口行为

- FR-010 L1 尺寸 96×6、仅露约 4px、主屏顶部中央。
- FR-011 鼠标进入顶部中央热区并连续停留 250ms 后展开为 L2；检测不得拦截下层窗口的点击。
- FR-012 鼠标离开 L2 及其安全边界 400ms 后自动收起为 L1；触摸、拖动、弹窗或编辑进行中时暂停收起计时。L3 鼠标离开后保持当前层级。
- FR-013 按 Esc：L3→L2、L2→L1；L3 顶栏同时提供可见“返回速览”按钮；存在未保存编辑时先提示处理。
- FR-014 触摸屏：点击提示条或从顶部中央向下滑动展开。
- FR-015 L2 默认 760×280、L3 最大工作区 85%；超出可用屏幕时按设计系统规则缩放或限高。
- FR-016 卡片横向滑动/滚轮带惯性与吸附；数据刷新不得跳回第一张卡片。
- FR-017 悬停展开不得激活窗口或抢走前台焦点；点击、触摸或键盘进入交互后才允许激活。
- FR-018 真正全屏前台窗口出现时暂停岛显示；离开全屏后 500ms 内恢复 L1（P6 实现）。
- FR-019 L1/L2/L3 使用单一透明窗口和一次原生尺寸提交完成切换；独显或集显可用时使用 compositor 过渡，硬件合成不可用时自动简化或直接切换。任何渲染模式都不得阻止应用启动、返回或采购操作。

### 4.3 任务数据与编辑

- FR-020 任务名称必填，去除首尾空白后长度 1–200 个 Unicode 字符。
- FR-021 任务字段：说明、可选 deadline、紧急度、Markdown 备注、线性时间轴节点、链接、提醒、kind（任务/杂事）、审计时间与排序信息。
- FR-022 紧急度固定为：紧急、高、普通、低；默认普通。
- FR-023 deadline 可为空；输入按用户当前系统时区解释，存储为 UTC 并保存所用时区 ID。
- FR-024 节点字段：标题（必填）、说明（可选）、开始时间（可选）、截止时间（可选）、状态、稳定顺序。
- FR-025 节点截止时间早于开始时间时禁止保存；节点时间超出任务 deadline 时警告，用户确认后可保存。
- FR-026 节点状态在待完成、进行中、已完成、已取消之间双向切换，并记录变更事件；状态必须通过显式选项选择，不得用单击循环推进。
- FR-027 任务进度 = 已完成节点数 / 有效节点数；已取消节点不进入分母也不参与下一节点计算；无有效节点时显示"尚未拆分"，不显示 0%。
- FR-028 杂事（kind=杂事）：标题 + 可选截止时间，无节点时间轴；可有关联链接与备注。
- FR-029 备注支持 Markdown（标题、段落、强调、列表、任务列表、链接、代码）；不解析原始 HTML、脚本、iframe 或远程嵌入内容。

### 4.4 排序与卡片

- FR-030 自动排序依次：紧急度（紧急到低）→ 是否有 deadline（有者优先）→ deadline 升序 → 创建时间升序 → 任务 ID 升序。
- FR-031 卡片主标题为任务名称，副标题为下一个有效节点；同时显示 deadline 或"未设置"、紧急度、节点完成比例和上一/当前/下一节点轴；逾期任务显示"已逾期"与逾期时长（红色描边+文字，不只靠颜色）。
- FR-032 普通左右滑动只浏览卡片，不改变顺序；带惯性与吸附；鼠标拖拽与滚轮等效。
- FR-033 自定义排序为后续增强：触摸长按 450ms 进入拖动重排；自动模式中不允许持久化手动重排。
- FR-034 点击卡片选中并保持横向浏览位置；Enter 或双击进入 L3 当前任务工作台。卡片支持方向键、Home/End 与可见焦点。
- FR-035 无活跃任务时显示简短空状态与"新建任务"引导，保持紧凑高度。
- FR-036 L2 节点轴上的节点是可访问控件，点击后显式选择四种状态；修改失败保留原状态并给出原因与重试入口。
- FR-037 L2 卡片右上角更多菜单提供完成、取消、删除；完成/取消进入可恢复归档，永久删除必须二次确认并延迟 5 秒提交，期间可撤销。

### 4.5 创建与 AI 规划

- FR-040 创建任务提供"AI 辅助"与"手动创建"两个同级入口；AI 失败可无损切换为手动模式。
- FR-041 兼容通道 Qoder MCP：采办岛内置本机 MCP 服务（SSE 为主、STDIO shim 备用），用户在 Qoder 中注册后即可对话；Qoder 调用采办岛工具只产生草稿（见 ARCHITECTURE.md 第 6 节）。
- FR-042 兜底通道：内置 OpenAI-compatible API（function call 结构化输出）；未配置 Key 时入口隐藏。
- FR-043 两通道输出统一草稿（建议任务摘要、deadline、紧急度、节点列表与警告），先进草稿审核，不得直接修改正式数据；草稿创建、编辑和确认必须执行同一套字段校验。
- FR-044 草稿审核支持逐节点保留、删除、编辑与排序，并可修改任务级建议字段。
- FR-045 用户确认前不创建正式任务、提醒或变更事件；确认时重新校验草稿结构、字段与目标任务有效性，通过后由应用服务在单个事务中写入，任一部分失败则整体回滚；提交后才发送数据变更通知。
- FR-046 LLM 结构化输出严格校验（日期、枚举、节点顺序、文本长度）；非法时自动修复一次，第二次失败后显示可理解错误并保留可手动编辑的失败草稿。
- FR-047 无 API Key、Qoder 未登录、断网、限流或模型拒绝，均不得阻止手动保存任务。
- FR-048 保存规划会话、模型输出草案与用户接受/修改/删除决策的审计记录；不保存 API Key、Authorization header 或敏感路径。

### 4.6 链接（网页 / 文件）

- FR-050 链接类型：URL 或文件路径；任务可关联任意数量，可编辑显示名称。
- FR-051 URL 仅允许 http/https；交给系统默认浏览器打开，打开前显示实际目标地址。
- FR-052 文件链接保存绝对路径与基础元数据（名称、大小、修改时间），不复制文件本体。
- FR-053 路径失效时显示不可用状态，允许重新定位。
- FR-054 用系统默认程序打开文件，或"在文件夹中定位"；打开前验证目标仍是文件且可访问。
- FR-055 节点与链接删除先从当前界面隐藏并显示 5 秒撤销；超时后才提交正式删除，提交失败时恢复原内容并显示可重试错误。

### 4.7 提醒

- FR-060 仅设有 deadline 的任务可配置提醒；每个任务可有多个不重复的提前量；默认不自动添加。
- FR-061 提醒用 Windows Toast 通知实现（无需证书：Electron 设置 AppUserModelID 并创建开始菜单快捷方式）；显示任务名称、deadline 与打开动作，不显示备注与敏感路径。
- FR-062 系统通知被禁用时降级为岛内轻弹：L1 平滑展开显示到期任务卡片，不抢焦点；设置页显示通知被系统阻止的状态。
- FR-063 创建、修改、取消、归档或恢复任务后，同步更新已计划的提醒。
- FR-064 因关机/睡眠漏发的提醒，在下次启动/唤醒时合并为一条摘要通知，避免逐条轰炸。

### 4.8 完成、取消与归档

- FR-070 完成或取消任务后，其生命周期变为 Archived，记录结果、操作时间与变更事件。
- FR-071 完成仍含未完成节点的任务时，列出这些节点并二次确认；确认后不自动更改节点状态。
- FR-072 取消任务必须确认，但不要求节点完成；节点状态原样保留。
- FR-073 归档时导出快照：archive/YYYY-MM/任务名/task.md（可读 Markdown）与 task.json（全量机器可读）；SQLite 同时保留归档记录。
- FR-074 归档页支持按文字、结果、紧急度、归档日期筛选；可打开完整只读历史视图；可恢复为活跃任务。
- FR-075 归档不删除链接元数据与快照；快照同名冲突时自动追加序号，不静默覆盖。

### 4.9 设置

- FR-080 MCP：地址与会话凭据默认遮罩；用户明确选择“显示”或“复制”后才暴露完整值；凭据使用 safeStorage 加密保存，旧版明文值启动时迁移并删除，失败时重新生成；重置后旧凭据不得创建新会话。STDIO 等实现说明收纳在高级帮助中。
- FR-081 AI：内置 API 配置（Base URL、API Key、模型名）与"测试连接"；Key 使用系统安全存储（Electron safeStorage）加密保存。
- FR-082 岛：暂停/恢复灵动岛；开机自启开关。
- FR-083 提醒：全局默认提前量开关。
- FR-084 数据：打开数据目录；说明归档快照目录。
- FR-085 外观：主题跟随系统并以深色为主要品牌呈现；磨砂关闭时用纯色回退；高对比度或系统减少动画开启时关闭磨砂与窗口过渡。
- FR-086 系统明暗、高对比度、减少动画与实际 backdrop 状态通过只读 preload API 提供给 renderer，系统设置变化后实时更新。

### 4.10 飞书多维表格同步

- FR-090 设置页配置：粘贴飞书多维表格个人令牌（PersonalBaseToken，safeStorage 加密保存）并"测试连接"。
- FR-091 目标表格：首次同步时在用户指定位置新建多维表格并创建"采办岛任务"数据表；或粘贴已有多维表格 URL 复用；应用内展示表格链接。
- FR-092 字段映射（v1 单表）：任务名称(文本)、类型(单选：任务/杂事)、紧急程度(单选：紧急/高/普通/低)、截止时间(日期)、状态(单选：进行中/已完成/已取消)、进度(数字 0-100，杂事留空)、下一节点(文本)、时间轴节点(多行文本，每节点一行含状态图标+标题+起止)、网页链接(文本)、文件链接(文本)、备注(多行文本)、采办岛任务ID(文本，幂等键)、最后同步时间(日期时间)。
- FR-093 同步语义：按"采办岛任务ID"检索表格记录，存在则更新、不存在则新增（batch_create/batch_update）；首次同步自动创建缺失字段；不删除表格中的其他记录。
- FR-094 自动同步：设置开关开启后，任务/节点/备注变更防抖 3s 后全量 upsert 活跃任务；失败保留并重试，岛内显示同步状态。
- FR-095 失败处理：令牌失效、无权限或表格被删时给出明确中文错误与操作指引；断网自动重试；任何失败不影响本地数据。
- FR-096 导出兜底：任务详情与归档页提供 CSV、Markdown 导出（含节点/链接/备注），供飞书多维表格"导入"使用；无令牌或企业禁用令牌时该通道始终可用。
- FR-097 安全：个人令牌与 API Key 同级待遇——safeStorage 加密保存、日志脱敏、不进入快照/备份/测试夹具。

### 4.11 原生 Pi Agent 与短期会话

- FR-100 Pi Agent 为默认原生通道，固定 `@earendil-works/pi-agent-core@0.81.1` 与 `@earendil-works/pi-ai@0.81.1`；Qoder MCP 和旧 OpenAI-compatible LLM 保持独立配置与回退能力。
- FR-101 首版只连接 `https://api.deepseek.com`；API Key 经 safeStorage 加密保存；默认 `deepseek-v4-flash`，可切换 `deepseek-v4-pro`。
- FR-102 L3 Agent 工作区支持本机会话列表、多轮对话、流式文本、取消、失败重试、删除、全部清空和 JSON/Markdown 导出；L1/L2 不承载长对话。
- FR-103 全局同时只运行一个 Agent run；单个 provider 请求 60 秒超时，整次 run 最长 3 分钟，最多 12 个模型轮次。收起 L3、切换工作区、用户取消或退出应用时中止运行。
- FR-104 只持久化用户可见文本、脱敏工具状态、模型、摘要与使用量；不得保存或显示模型内部 reasoning、完整工具原始结果、API Key 或 Authorization。
- FR-105 任务数据工具固定为 `list_active_tasks`、`get_task_detail`、`propose_task_draft`、`propose_node_draft`、`propose_task_action`；不得提供文件、shell、URL 请求或额外网络工具。
- FR-106 `propose_task_action` 一次只产生一个操作提案，只允许节点四态、提醒增删及节点新增、修改、删除、重排；禁止修改任务名称、说明、deadline、紧急度，禁止完成、取消、归档、恢复和永久删除任务。
- FR-107 每个轻量操作显示前后差异并逐次确认；提案保存预期旧值，确认时乐观并发检查。数据变化、重复确认、过期或非法 payload 均拒绝执行并要求重新规划。
- FR-108 节点删除在操作提案确认之外额外二次确认，并提供 5 秒撤销；所有确认与审计事件在同一事务提交，提交后才发送正式数据变更通知。

### 4.12 长期记忆与跨会话召回

- FR-109 长期记忆分为“用户画像”和“工作 / 业务记忆”。Agent 只能调用 `propose_memory` 提议 add/replace/remove，并引用当前会话中的用户可见证据消息；用户可编辑、确认或拒绝。
- FR-110 未确认提案永不进入系统提示。已确认记忆只在新建会话或重新载入既有会话时获取一次快照；当前已加载会话不会在后台静默改变上下文。
- FR-111 用户画像容量 1,375 字符，工作 / 业务记忆容量 2,200 字符；达到 80% 显示合并/删除建议，超过上限拒绝确认，禁止静默淘汰。
- FR-112 确认或直接编辑已确认记忆前必须执行规范化去重、不可见 Unicode、提示注入、凭据/Authorization 和私人/临时路径扫描；单条事实最多 360 字符。
- FR-113 每条确认记忆保留来源会话、证据消息、创建与最后修改时间；支持编辑、单条删除和全部清空。清除记忆不影响正式任务与会话历史。
- FR-114 `search_sessions` 只读工具使用本地 FTS5 搜索用户/Agent 可见消息，只返回匹配片段、首尾摘要与有限上下文；不返回 reasoning、工具原始输出、凭据或文件内容。
- FR-115 Pi 工具 allowlist 在 FR-105 五项基础上增加 `propose_memory` 与 `search_sessions`；仍不得访问任意文件、shell、URL 或额外网络。
- FR-116 P15 不导入或索引用户文档；任务、记忆、历史会话和未来知识库通过独立 `AgentContextProvider` 注入，知识库不得与短小行为记忆共表。

## 5. 数据与存储

- 主库：%APPDATA%\caiban-island\island.db（SQLite、WAL、外键、版本化迁移）；
- Agent 会话：同一主库的 `agent_sessions` / `agent_messages`（本机长期保留，用户可删除、清空或导出）；
- 长期记忆：同一主库的 `memories` / `memory_proposals`；会话可见消息由本地 `agent_messages_fts` 索引；
- 快照：%APPDATA%\caiban-island\archive\YYYY-MM\任务名\task.md 与 task.json；
- 自动备份：启动时备份 island.db 至 backups\，保留最近 7 份；
- task.json 结构：format_version、exported_at、app_version、task、nodes、links、notes、change_events；
- task.md 结构：任务名称、deadline、紧急度、说明、节点清单（含状态）、链接清单、备注正文。

## 6. 边界条件与失败模式

- 多显示器：岛固定主显示器；L3 可拖动并记忆位置。
- DPI 缩放 100%/125%/150%：窗口按逻辑像素换算，per-monitor 感知。
- 高对比度 / 系统"减少动画"开启：禁用磨砂与过渡动画，使用系统颜色回退（见 DESIGN_SYSTEM.md）。
- 断网 / Qoder 未登录 / 未配 API：手动模式完整可用。
- LLM 输出非法：严格 schema 校验，自动修复一次，再失败转可编辑失败草稿。
- 链接 / 文件失效：标灰显示，可重新定位；打开失败给出可操作提示。
- 逾期任务：红色描边 + "已逾期"文字 + 轻呼吸动画。
- 节点/链接删除提供 5 秒撤销；任务完成与取消使用二次确认。
- 数据损坏：启动时检测，自动从最近备份恢复；无法恢复时重建并提示。
- MCP 端口被占用：自动更换随机端口并更新设置页地址。
- SmartScreen 首次提示"仍要运行"：README 说明，属无证书应用正常现象，非报毒。

## 7. 验收标准

- AC-01 Windows 独立运行版在干净 Win10 1809 与 Win11 机器上双击即用，无需安装证书。
- AC-02 L1 隐藏态凸出 ≤4px 且不拦截下层点击；鼠标移上 250ms 内平滑展开。
- AC-03 卡片按紧急度排序正确；触摸左右滑动跟手、带惯性吸附；点击进入详情。
- AC-04 详情页展示名称、deadline、时间轴、节点完成情况、全部 URL/文件链接、备注。
- AC-05 Qoder 对话产生草稿 → 岛内审核（保留/删除/修改/排序）→ 确认生成卡片；后期可改时间轴与节点。
- AC-06 节点四态切换即时生效，颜色为绿/蓝/黄/中性灰，已取消节点不阻塞进度与下一步，视觉遵循设计系统。
- AC-07 任务结束/取消后卡片消失，快照与记录本地归档，可在归档页搜索查看并恢复。
- AC-08 展开/收起/滑动动画 60fps；磨砂透出桌面色彩；不可用时自动回退纯色。
- AC-09 配置个人令牌后一键同步，任务记录出现在多维表格且字段正确；再次同步幂等更新；令牌失效给出可操作错误；无令牌时 CSV 导出可用。
- AC-10 L2 三秒内可识别下一采购动作；L3 默认聚焦当前任务且日常区与高级设置不同时铺开。
- AC-11 主题跟随系统；键盘可完成任务浏览、分区导航、显式状态选择和撤销；正文与控件满足 WCAG AA。
- AC-12 100 个任务时 L2 最多挂载 7 张任务卡；每次层级切换最多一次原生 resize；集显、软件渲染和 GPU 进程异常降级后三级界面仍全部可达。
- AC-13 Pi Agent 可完成多轮任务读取与草稿规划；轻量操作确认前不生效，确认后只执行一次；取消、超时和轮次上限保留输入与会话，reasoning 与 Key 不进入存储或导出。
- AC-14 记忆提案确认前不注入；安全扫描、去重和有界容量生效；重载会话后注入最新确认快照；FTS5 召回不包含 reasoning 或工具原始输出。
