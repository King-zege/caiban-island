## 2. 单元测试清单

- 排序：紧急度→是否有 deadline→deadline 升序→创建时间→ID；逾期表现；空列表。
- 校验：名称 1–200 字符；节点起止时间关系；枚举合法性；UTC/时区换算往返。
- 进度计算：0 有效节点=尚未拆分；已取消节点排除；完成数/有效节点数。
- 快照格式：task.json 字段完整性与 format_version；task.md 结构。
- Markdown 安全：原始 HTML/script/iframe 被剔除。
- Agent/AppCommand schema 校验：合法样例通过；缺字段、坏枚举、多余字段与错序参数在 main 边界拒绝。
- UI 偏好：明暗、高对比度、减少动画与 backdrop 组合；系统变化后状态同步。
- 窗口几何：Windows 最小原生高度下 L1 仍只进入工作区 4–6px；多 DPI 使用逻辑像素。
- 撤销队列：5 秒内撤销不调用正式删除；超时只提交一次；失败恢复可见内容。
- 过渡：阶段顺序、旧 id 忽略、80ms/280ms 超时、preparing 取消、动画中末次请求合并、显示器变化后落到新几何。
- 渲染能力：GPU 状态分类为 composited/software/direct；未知状态保守降级；高对比度、减少动画和 GPU 进程异常强制 direct。
- 虚拟 Carousel：0/1/7/100 项、可见范围与两侧 overscan、全局索引焦点、Home/End、触摸/滚轮后吸附。
- 节点时间：任务时区与 UTC 往返（含 DST 不存在时间）、活跃节点过去时间拒绝、截止早于开始拒绝、超任务 deadline 二次确认、`expectedStartUtc` 并发冲突。
- 任务紧急度：四档枚举、选择当前值不写入、`expectedUrgency` 冲突拒绝、只更新目标字段、审计事件与 `AppService` 变更通知一次。
- 名称编辑：任务/节点 1–200 字符复用校验、选择原值不写入、预期旧值冲突拒绝、只更新名称字段、审计事件与 `AppService` 变更通知一次。

## 3. 集成测试清单

- SQLite：CRUD、事务回滚、WAL、迁移升级路径、外键级联。
- 归档：完成/取消 → 快照导出 → 归档查询 → 恢复往返；重名快照自动加序号。
- 提醒：项目提前量、节点准时提醒与杂事精确提醒并存；只领取实际到期 ID；未设时间不调度，相同时间不重置、修改时间重置；完成/取消/删除/归档取消，恢复只重建未来提醒；启动/唤醒漏发合并且重复扫描不重复。
- 本地命令端点：只绑定回环；校验 Content-Type、体积、令牌和完整 AppCommand schema；非法/多余字段拒绝，命令不得启动 shell 或转发网络。
- DeepSeek 适配器：模型列表连接测试；受控流覆盖文本、工具调用、空响应、异常终止、401、429、5xx、断流与超时。
- Pi Agent：faux provider 完成真实多轮工具循环与生成/修改/删除卡片、整理授权文件验收；mock runner 验证单 run、取消、上限、流式映射与会话持久化；自动化不使用真实 Key。
- Pi 打包：构建配置必须内联两个纯 ESM Pi 包；最终 main bundle 不得残留 `require("@earendil-works/pi-*")`，portable 双击启动不得出现 `ERR_PACKAGE_PATH_NOT_EXPORTED`。
- 轻量操作：allowlist/schema、确认前不生效、重复确认、过期/旧值冲突、节点增改删排与提醒提案；删除二次确认和撤销。
- 长期记忆：add/replace/remove 提案确认前不生效；编辑确认、拒绝、直接维护、来源时间、1,375/2,200 字符容量与 80% 警告。
- 记忆安全：规范化重复、不可见 Unicode、提示注入、凭据/Authorization、私人/临时路径和单条长度均在写入前拒绝。
- 会话召回：FTS5 迁移/索引、首尾摘要、有限上下文、tool 消息过滤；会话新建/重载才刷新确认记忆快照。
- 飞书：mock bitable server 建表/建字段/按任务ID upsert 幂等；令牌失效错误与重试；CSV/Markdown 导出格式。
- Renderer：L2 方向键/Home/End/Enter、项目紧急度排序与菜单、资料懒载入、节点四态/时间、任务/节点重命名、双层内容模式、杂事贴纸虚拟化与立即完成反馈；L3 分组任务导航、项目五页签、杂事单页、旧 deadline 提示、提醒/备注/资料管理与通知定位；设置直达，Dialog 焦点锁定和恢复，Toast live region，凭据默认遮罩，外链确认。
- L2 Agent：默认任务卡片、切换 Agent、L2/L3 共享会话与 run snapshot、流式文本、隐藏继续、显式取消、最近会话、三档权限和待确认队列；任务操作后刷新凭条/贴纸，删除按模式确认，记忆提示下一次会话注入。
- 草稿修订：sessionId 往返、跨会话/跨类型/非 pending 替换拒绝、失败事务不改变旧稿、superseded 不可确认且不进入 pending 列表。
- 归档案例：查询长度与数量上限、稳定排序、只读；结果不包含 note、URL/file target、绝对路径、快照正文、事件 detail 或凭据模式。
- Agent 完成通知：当前可见时不发送；后台完成使用通用正文；点击恢复正确 session/提案；通知失败、岛暂停和真正全屏均遵守退让与延后语义。

## 5. 性能目标

- 展开/收起/滑动动画 60fps（devtools 性能面板核对，无明显掉帧）。
- 冷启动 < 2s；常驻内存 < 250MB（Electron 基线）。
- 100 个活跃任务时列表滚动与排序不卡顿。
- 合成模式每次切换最多一次 resize，请求到首个视觉帧 ≤50ms，`animating` 至 `settling` 的视觉过渡 200±40ms；100 任务的 animating 阶段 rAF 间隔不得出现 >50ms、>20ms 间隔占比 <5%，完整切换由 Long Tasks API 验证无 >50ms 主线程长任务。使用 `npm run benchmark:transitions -- <CDP 端口> --assert` 验证；端口对应的 Electron 必须以隔离临时目录和 100 条合成任务启动。
- 普通 L2 在 100 任务时 DOM ≤700、实际 TaskCard ≤7；软件/direct 模式允许降低动效，但启动、返回和全部采购操作必须可用。

## 6. 安全验收

- 全仓与测试数据目录扫描：无明文 API Key / 本地命令令牌 / PersonalBaseToken / Authorization（grep + 提交前检查）；令牌只允许以 safeStorage 密文存在。
- 日志无请求正文与敏感路径；快照与备份无凭据。
- 本地命令端点仅绑定 127.0.0.1；令牌不出现在日志、快照、导出或测试夹具中。

## 7. 打包验收

- GitHub 推荐的 Windows x64 独立 EXE 在干净环境双击运行；本地 zip 解压冒烟继续作为打包验收，卸载=删除应用文件。
- 首次运行 SmartScreen 提示与 README 说明一致。
- 开机自启注册/取消正确；卸载不残留多余注册表项。
