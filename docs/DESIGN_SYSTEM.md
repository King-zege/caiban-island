# 采办岛 v1 设计系统

## 1. 设计方向

借鉴 Apple Live Activities / Dynamic Island 的信息层级与连续动效，而非复制 iPhone 外形。遵循：

1. **一眼可读**：L1 只表达入口，L2 将采购项目与杂事分层展示，复杂编辑进入 L3。
2. **连续变化**：同一内容在 L1/L2/L3 之间保持空间关系，避免突然换页。
3. **材质克制**：仅 L2/L3 外壳使用系统 Acrylic；内部主要用留白、分组与细分隔建立层级，禁止卡片套卡片。
4. **不打断工作**：悬停不抢焦点，自动收起可预测，全屏场景主动退让。
5. **信息不依赖颜色**：图标、文字、形状与颜色共同表达状态。

参考：Apple Materials 与 Live Activities 设计指南；Windows 桌面 Acrylic（Win10 1803+/Win11 经 SetWindowCompositionAttribute 实现）。

## 2. 设计 Token

### 2.1 颜色（跟随系统；高对比度模式改用系统颜色）

| Token | 深色值 | 浅色值 | 用途 |

### 2.2 圆角与边框

| Token | 值 | 用途 |
| --- | --- | --- |
| Radius.L2 | 32px | L2 外轮廓 |
| Radius.L3 | 24px | L3 外轮廓 |
| Radius.Collapsed | 999px | L1 提示条胶囊 |
| Radius.Section | 16px | 任务卡片、详情分区 |
| Radius.Control | 12px | 输入框、按钮、菜单 |
| Radius.Chip | 999px | 状态、紧急度、筛选标签 |
| Border.Subtle | 1px | 低对比分隔 |
| Border.Focus | 2px | 键盘焦点环，外偏移 2px |

所有可见矩形面必须使用以上圆角层级之一；嵌套圆角遵循外大内小，避免内层切到外轮廓。

### 2.3 间距

基础间距单位 4px：4 / 8 / 12 / 16 / 20 / 24 / 32。任务卡片内边距 16px，L3 内容分区 24px，岛外边缘安全内距 12px。

### 2.4 字体

- 字体：Segoe UI Variable，回退 Segoe UI。
- Display：28/34 Semibold（L3 标题、空状态）；Title：20/26 Semibold（速览标题）；Card Title：16/22 Semibold（最多两行省略）；Body：14/20 Regular；Caption：12/16 Regular（deadline、紧急度、元数据）。
- 重要倒计时使用 tabular numerals，避免数字变化引起宽度跳动。
- Windows 文本缩放开启后允许内容增高与滚动，禁止缩小字体维持固定高度。

## 3. 三级形态规格

### 3.1 L1 隐藏条

- 视觉条 96×6 逻辑像素；原生窗口可使用 Windows 最小高度，但必须上移到只有底部 4–6px 进入工作区；贴屏顶一侧平直，朝屏幕中心的下侧使用胶囊圆角；
- 主显示器顶部中央；L1 禁用原生 Acrylic，窗口其余区域完全透明，无文字无计数；
- 触发热区约 120×10（顶部中央），用屏幕坐标轮询实现，禁止拦截式透明覆盖窗口。

### 3.2 L2 小面板

- 默认 760×280；宽 560–主屏工作区 80%，高 ≤工作区 45%；外距 12；
- 顶部使用“任务卡片 / Agent”双项分段切换；首次进入默认任务卡片。Agent 使用 760×480 详细高度，任务卡片继续按内容模式使用 196/280/376px；切换只做一次原生 resize；
- Agent 以单一消息轨道为主体：顶部显示会话名、模型、运行阶段和权限，中部滚动消息及脱敏工具状态，底部固定输入与发送/取消。运行中提供带文字的“隐藏并继续”，不得把收起表达成取消；
- 待确认命令紧接对应 Agent 消息，以平面差异条呈现风险、旧值和新值；批准后继续当前工具循环，拒绝或取消结果反馈给 Agent。遗留草稿沿用确认/丢弃入口并内联呈现；
- 多个提案按时间形成有序队列并逐项处理；完成通知打开后聚焦提案标题。任务确认成功后切到任务速览并定位新凭条/贴纸；
- 顶部工具行 52px，只显示新建、展开、更多；排序与设置位于更多菜单；
- 采购凭条 248×176、间距 12；宽度足够时露出下一张边缘；
- 凭条从上到下突出任务名称、下一节点、风险/截止与可交互节点轴；紧急度标签是与卡片主体分离的真实菜单按钮，点击后显式选择紧急、高、普通或低并标记当前值，不循环切换；紧急度与节点操作浮层必须使用不透底的 `Color.Surface.Fallback`，不得让卡片文字穿透后与菜单项重叠。节点轴优先显示上一/当前/下一节点，右上角更多菜单与卡片主体同样使用分离控件。节点本身是菜单按钮，点击后打开包含四态与提醒时间入口的浮层，不直接循环状态；已设置时间时节点名称旁显示 11px 线性时钟标记。
- 紧急度与节点菜单均使用不小于 44×44px 的菜单项，当前状态同时以 `aria-checked`、勾选图标和文字表达；菜单支持方向键、Home/End、Enter/Space 与 Esc，关闭后焦点返回原按钮。菜单与时间对话框都必须隔离卡片拖动和进入 L3 的点击行为。
- “设置/修改提醒时间”打开 L2 内的轻量对话框，操作期间扩展 L2 交互区并暂停自动收起；日期时间输入按任务时区显示，提供保存、清除提醒和取消。完成/取消节点的入口禁用并显示“恢复节点后可设置”。
- 卡片右上角使用带下拉语义的资料与操作按钮：弹层使用不透明回退底色、最大宽度 320px 与受限滚动高度，先展示按需载入的网页/文件名称和目标摘要，再展示任务重命名与生命周期操作；空、载入、失败和重试状态不得与卡片正文叠放。
- 任务名在卡片下拉与 L3 标题旁、节点名在节点菜单与 L3 节点行均提供铅笔编辑键。编辑使用单字段轻量对话框，打开时选中文本；保存失败保留输入，成功后 Toast 说明修改对象，Esc 关闭并恢复触发按钮焦点。
- L2 内容区按“采购项目”“杂事”上下分层。采购项目继续使用 248px 宽采购凭条；杂事使用约 216×88px 的低矮工作单，标题最多两行，底部只显示时钟图标与“无提醒/具体时间/已提醒”。两层各自横向虚拟化，分组标题和数量是结构信息而非装饰。
- 杂事工作单不使用黄色纸张、旋转、胶带或阴影堆叠。它复用 `Surface.Raised`、细边界与单一冰蓝焦点，通过更低高度、平直信息结构和独立 44px 完成控件与项目凭条形成差异。正文按钮进入 L3，完成按钮不得触发卡片拖动或导航。
- L2 原生高度由内容模式决定：空/仅项目 280px、仅杂事 196px、混合 376px；详细交互 480px。超出屏幕上限时限高并让内容区滚动，形变仍只提交一次原生 resize。

### 3.3 L3 大面板

- 最大为主屏工作区 85%，外距 24；圆角 24px；
- 使用 240px 左侧任务栏 + `minmax(0, 1fr)` 当前任务工作区；主内容阅读宽度不超过 960px；
- 任务侧栏使用“采购项目”“杂事”分组。采购项目工作区分为概览、采购节点、资料、提醒、备注，一次渲染一个主分区；
- 杂事不显示页签和紧急度徽标，使用单页工作区依次呈现名称、精确提醒、备注、资料和生命周期操作。内容通过分隔线与留白组织，不新增嵌套卡片；
- 概览事实区的紧急程度使用四档分段按钮，当前值使用 `aria-pressed`、文字与对应的小面积状态色共同表达；保存期间禁用整组，结果通过 Toast 反馈；
- 节点轨迹横向展开；状态使用显式选择器，线型、图标、文字与颜色共同表达；每个节点提供独立时间按钮，开始时间文案为“到时提醒”，截止时间为“仅用于计划”，提醒通知定位的节点使用短暂高亮但不改变状态；
- Agent、记忆、归档、设置位于侧栏次级入口；L3 不再显示“AI 草稿”；窄屏顶部保留任务选择及上述入口；设置分常用、Agent、飞书同步、数据与高级；
- L3 顶栏始终提供带文字的“返回任务卡片”按钮；鼠标离开不改变 L3 层级；
- L2 默认任务卡片并可切换 Agent；L2 与 L3 渲染同一个 `AgentWorkspace`，共享会话、消息、权限、工具状态、错误、重试和待确认操作。两层只允许布局密度不同，不得隐藏功能；L2 Agent 展开进入 L3 同一会话，从 L3 返回一律回到 L2 任务卡片；
- Bypass 模式始终使用警示色标识，首次启用必须展示风险确认；待确认调用以内联差异卡呈现，批准、拒绝与取消均可键盘操作并恢复焦点；
- 所有触控目标 ≥44×44，相邻目标间距 ≥8px。

### 3.4 形态过渡

- 同一窗口连续形变；每次层级切换最多一次原生 resize，禁止高频修改 width/height/top/left 模拟动画；
- `composited` 模式使用 200ms transform/opacity/border-radius 视觉壳：源内容前 80ms 淡出，目标内容从第 60ms 淡入；
- `software` 模式使用 120ms 纯淡入淡出，不动画圆角与阴影；`direct`、高对比度或系统“减少动画”模式单帧切换；
- 过渡期间临时使用 `Color.Surface.Fallback`，完成后恢复实际 backdrop；层内 content-enter 动画在窗口切换期间暂停，避免多重运动；
- L1→L2 不抢焦点；L2→L3 完成后聚焦当前任务标题；L3→L2 恢复原任务卡。动画期间所有目标控件不可交互。

## 4. 任务卡片

从上到下：

1. 任务标题（最多一行，超出省略号）；
2. 下一个有效节点（使用一次“下一步”短标签，不重复“下一采购动作”）；
3. deadline、逾期与可调整的紧急度按钮；普通紧急度不使用强调色；
4. 上一/当前/下一节点轴、四态显式选择与已完成节点数 / 有效节点数；
5. 右上角更多菜单承载任务完成、取消和删除；可访问名称汇总上述信息（读屏器友好）。

杂事工作单：L2 使用独立低矮工作单，不显示紧急度、deadline、进度或下一节点；L3 使用无页签单页。提醒状态必须同时使用时钟图标和文字，不以颜色单独表达。

## 5. 动效规范

- 展开/收起：合成视觉壳 200ms，软件模式 120ms，原生窗口只提交最终几何；卡片进入/删除：位移+缩放+淡入淡出；
- 滑动：跟手位移、松手按速度惯性滚动并吸附最近卡片，阻尼平滑；
- 状态切换：线型、图标与颜色在 160ms 内同步变化；不使用常驻呼吸动画；
- 全部动效可被系统"减少动画"设置一键关闭（回退规则见 3.4）；轮播在该模式下保留直接拖动反馈，松手、滚轮和键盘定位直接吸附，不运行惯性或补间。

## 6. 触控与可访问性

- 触控目标 ≥44×44；支持触摸滑动；长按 450ms 拖拽重排为后续版本；
- 键盘：Tab 焦点顺序为 L2 工具行→卡片主体→资料下拉→紧急度按钮→节点按钮；卡片支持方向键、Home/End，Enter/Space 激活；资料、紧急度与节点菜单内部使用方向键/Home/End，Esc 只关闭菜单并恢复触发按钮焦点；L3 侧栏与工作区顺序稳定；无弹窗/菜单时 Esc 层层返回；
- 焦点环 2px #64D2FF；状态不只用颜色表达（图标+文字）；
- Dialog 使用 `aria-modal`、焦点锁定并在关闭后恢复焦点；Toast 使用 live region；
- 高对比度或减少动画模式：关闭磨砂和窗口/内容过渡，使用系统颜色；正文对比度满足 WCAG AA。
