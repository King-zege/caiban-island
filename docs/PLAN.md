# 采办岛 开发计划

## 1. 背景

旧版 DeskManager（WinUI 3 + .NET 10、签名 MSIX、仅 Win11）作为设计与规格参考；新版「采办岛」以 Electron 重写，目标 Win10(1809+)/Win11、免证书免安装分发、灵动岛三级面板、原生 Pi Agent 与飞书多维表格同步。旧版 docs/（PRODUCT_SPEC、DESIGN_SYSTEM、ARCHITECTURE、TEST_PLAN）的设计资产已移植并扩充到本仓库。

## 2. 决策记录

| 决策点 | 结论 | 理由 |
| --- | --- | --- |
| 技术栈 | Electron + TypeScript + React 19 + Vite + Node `node:sqlite` | Electron 内置 Node 24；无需原生 SQLite 扩展重编译 |
| 分发 | 免证书独立运行 EXE；zip 仅用于本地验收 | 用户要求 GitHub Release 保持单一、清晰、可信的下载项；SmartScreen 提示可接受 |
| 界面 | 岛内三级 L1/L2/L3，无独立主窗口 | 用户确认；托盘承接常驻控制 |
| Agent 通道 | Pi Agent + DeepSeek 官方 API；Qoder MCP 与旧内置 LLM 已在 P21 移除 | 单一原生工作区、单一协议与可恢复运行状态 |
| 本地自动化 | AppCommand 回环端点 + `caiban-cli` | 只允许注册命令，不提供任意 shell、网络或未授权目录 |
| 节点色 | 已完成=绿、进行中=蓝、待完成=黄、已取消=中性灰 | P11 用户确认增加取消状态；取消节点排除进度与下一步 |
| 折叠形态 | 96×6px 仅露约 4px 提示条 | 用户确认不遮挡浏览器标签/窗口按钮 |
| 滑动 | 左右滑动浏览卡片（惯性+吸附） | 用户确认 |
| 杂事 | 轻量任务：名称、备注、资料与一个精确提醒时间，无节点、deadline 或紧急度 | P19 用户确认 |
| 提醒 | 项目 deadline 提前量 + 节点 startUtc + 杂事精确时间；Windows Toast + 岛内轻弹降级 | P16/P19 用户确认：未设置则不提醒 |
| 存储 | SQLite 主库 + Markdown/JSON 快照归档 | 查询可靠 + 快照可读可迁移 |
| 工程纪律 | 每个节点：测试机制 → 全部通过 → 一次 git commit | 用户要求 |
| 飞书同步 | 内置 bitable v1 Open API + PersonalBaseToken；CSV/Markdown 导出兜底 | 企业飞书免管理员审批的最低成本沉淀；无 CLI 依赖 |
| P8–P10 视觉方向 | 精密采购工作台；Apple 式信息层级与渐进披露，但不模仿 macOS | 用户确认全量重做；下一采购动作优先，功能完整但不堆叠入口 |
| 主题与结构 | 跟随系统、深色优先；L3 默认当前任务工作台 | 用户确认；高级设置按需展开 |
| P12 切换架构 | 单次原生 resize + compositor 视觉壳；集显完整、软件渲染降级 | 用户选择最大流畅度，并要求无独显电脑仍可运行 |
| P13–P15 Agent（历史） | Pi v0.81.1、DeepSeek 与旧兼容通道的阶段性实现 | P21 已以三档权限和单一 Agent 通道取代旧回退规则 |
| P16 节点操作 | L2 节点点击打开四态+时间菜单；L3 保留完整起止计划 | 用户确认：L2 不直接循环状态，节点开始时间到点提醒 |
| P17 任务紧急度 | L2 卡片使用四档菜单按钮；L3 概览使用四档分段按钮；专用 IPC 做旧值校验 | 用户要求创建后仍可直接调整普通、紧急等任务重要程度 |
| P18 L2 资料与名称 | L2 默认按 shared 紧急度规则排序；卡片下拉按需展示链接/文件；任务与节点使用专用并发安全重命名接口 | 用户要求紧急任务前置、L2 速览资料并可后续编辑名称 |
| P19 任务分层 | L2 项目凭条+杂事工作单双层布局；L3 杂事单页；精确提醒；AI 分类草稿 | 用户要求大项目与日常杂事在 L2/L3 形成清晰分层 |
| P20 L2 Agent（历史） | L2 曾默认完整 Agent 对话；后台运行、完成通知、只读内联确认与归档案例检索 | 已由 P21 的任务卡片默认态、统一工作区和权限化原生操作取代 |
| P21 统一 Agent 工作区 | L2 默认任务卡片；L2/L3 共用 AgentWorkspace；三档权限；AppCommand、授权目录、受限 CLI；事件快照补偿 | 用户要求 Agent 像原生能力一样安全操作应用，并修复发送后无回应 |

## 4. 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| Win10 老显卡磨砂失败 | 视觉降级 | 纯色 #111216 回退 |
| 企业网络/杀软拦本地端口 | 本地 CLI 不可用 | GUI 功能不受影响；仅回环端口占用时自动更换 |
| Agent 权限误配置 | 自动写入范围超出预期 | Bypass 首次确认、持续警示、授权目录与命令边界不可绕过 |
| Electron 内存偏高 | 常驻成本 | 可接受；性能目标 <250MB |
| GPU 合成不可用或进程异常 | 动效降级 | 自动切换 software/direct；不影响窗口与业务功能 |
| SmartScreen 提示 | 用户疑虑 | README 说明非报毒 |

## 5. 遗留问题 / 后续增强

- 自定义排序（长按拖拽重排）；
- Arm64 安装包；
- 多显示器多岛；
- 节点依赖关系与子节点；
- 附件托管（复制文件本体）；
- 数据加密与导出密码保护；
- 飞书双向同步；OAuth 自建应用通道（需企业管理员审批）。
- 私人知识库（文件授权、来源追踪、分块、全文/向量检索与删除同步；不与行为记忆混表）。
