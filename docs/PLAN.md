# 采办岛 开发计划

## 1. 背景

旧版 DeskManager（WinUI 3 + .NET 10、签名 MSIX、仅 Win11）作为设计与规格参考；新版「采办岛」以 Electron 重写，目标 Win10(1809+)/Win11、免证书免安装分发、灵动岛三级面板、原生 Pi Agent 规划、Qoder MCP 兼容与飞书多维表格同步。旧版 docs/（PRODUCT_SPEC、DESIGN_SYSTEM、ARCHITECTURE、TEST_PLAN）的设计资产已移植并扩充到本仓库。

## 2. 决策记录

| 决策点 | 结论 | 理由 |
| --- | --- | --- |
| 技术栈 | Electron + TypeScript + React 19 + Vite + Node `node:sqlite` | Electron 内置 Node 24；无需原生 SQLite 扩展重编译 |
| 分发 | 免证书独立运行 EXE；zip 仅用于本地验收 | 用户要求 GitHub Release 保持单一、清晰、可信的下载项；SmartScreen 提示可接受 |
| 界面 | 岛内三级 L1/L2/L3，无独立主窗口 | 用户确认；托盘承接常驻控制 |
| AI 兼容通道 | Qoder（独立桌面 IDE）MCP：SSE 为主 + STDIO 备用 | P5 已交付，P14 后继续作为无需 API Key 的兼容与故障回退 |
| AI 兜底 | 内置 OpenAI-compatible API（未配 Key 时入口隐藏） | 用户选择：Qoder 为主 + 兜底通道 |
| 节点色 | 已完成=绿、进行中=蓝、待完成=黄、已取消=中性灰 | P11 用户确认增加取消状态；取消节点排除进度与下一步 |
| 折叠形态 | 96×6px 仅露约 4px 提示条 | 用户确认不遮挡浏览器标签/窗口按钮 |
| 滑动 | 左右滑动浏览卡片（惯性+吸附） | 用户确认 |
| 杂事 | 轻量任务：一句话+可选截止时间，无节点 | 用户确认 |
| 提醒 | 任务 deadline 提前量 + 节点 startUtc 准时提醒；Windows Toast + 岛内轻弹降级 | P16 用户确认：L2 节点菜单直接设置一个精确提醒时间；未设置则不提醒 |
| 存储 | SQLite 主库 + Markdown/JSON 快照归档 | 查询可靠 + 快照可读可迁移 |
| 工程纪律 | 每个节点：测试机制 → 全部通过 → 一次 git commit | 用户要求 |
| 飞书同步 | 内置 bitable v1 Open API + PersonalBaseToken；CSV/Markdown 导出兜底 | 企业飞书免管理员审批的最低成本沉淀；无 CLI 依赖 |
| P8–P10 视觉方向 | 精密采购工作台；Apple 式信息层级与渐进披露，但不模仿 macOS | 用户确认全量重做；下一采购动作优先，功能完整但不堆叠入口 |
| 主题与结构 | 跟随系统、深色优先；L3 默认当前任务工作台 | 用户确认；高级设置按需展开 |
| P12 切换架构 | 单次原生 resize + compositor 视觉壳；集显完整、软件渲染降级 | 用户选择最大流畅度，并要求无独显电脑仍可运行 |
| P13–P15 Agent | Pi v0.81.1 为原生默认 Agent；DeepSeek 官方 API；Qoder 与旧 LLM 保留回退 | 锁定上游与最小依赖；所有正式修改逐次确认；长期记忆必须经用户审核 |
| P16 节点操作 | L2 节点点击打开四态+时间菜单；L3 保留完整起止计划 | 用户确认：L2 不直接循环状态，节点开始时间到点提醒 |

## 4. 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| Win10 老显卡磨砂失败 | 视觉降级 | 纯色 #111216 回退 |
| 企业网络/杀软拦本地端口 | MCP SSE 不可用 | STDIO shim；端口占用自动更换 |
| Qoder 版本差异 | 注册步骤不同 | README 提供双传输说明 |
| Electron 内存偏高 | 常驻成本 | 可接受；性能目标 <250MB |
| GPU 合成不可用或进程异常 | 动效降级 | 自动切换 software/direct；不影响窗口与业务功能 |
| SmartScreen 提示 | 用户疑虑 | README 说明非报毒 |

## 5. 遗留问题 / 后续增强

- 自定义排序（长按拖拽重排）；
- Arm64 安装包；
- 多显示器多岛；
- 节点依赖关系与子节点；
- 附件托管（复制文件本体）；
- 数据加密与导出密码保护；
- 飞书双向同步；OAuth 自建应用通道（需企业管理员审批）。
- 私人知识库（文件授权、来源追踪、分块、全文/向量检索与删除同步；不与行为记忆混表）。
